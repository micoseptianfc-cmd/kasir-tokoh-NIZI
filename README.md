Kasir Tokoh NIZI 🛒
Aplikasi Point of Sale (POS) berbasis web offline yang dirancang khusus untuk mengelola transaksi penjualan toko ritel dengan cepat, akurat, dan aman.

🚀 Fitur Utama
Manajemen Produk & Stok: Pengelolaan data barang masuk dan stok keluar secara real-time.

Kasir & Transaksi: Antarmuka kasir (kasir.php) yang ramah pengguna untuk mempercepat proses transaksi penjualan.

Laporan Keuangan: Rekapitulasi laporan penjualan dan keuangan toko secara berkala.

Keamanan Data: Sistem berjalan secara offline di komputer lokal dengan perlindungan file konfigurasi database yang aman dari publik.

💻 Teknologi yang Digunakan
Bahasa Pemrograman: PHP Native & JavaScript

Database: MySQL (dikelola via phpMyAdmin)

Server Lokal: XAMPP

⚙️ Cara Instalasi & Menjalankan (Offline)
Clone atau unduh repository ini ke dalam folder htdocs di direktori XAMPP Anda (C:/xampp/htdocs/).

Buat database baru di MySQL/phpMyAdmin.

Import file database yang tersedia di folder database/.

Sesuaikan konfigurasi koneksi database pada file config/koneksi.php.

Jalankan Apache dan MySQL melalui XAMPP Control Panel, lalu buka aplikasi melalui browser dengan mengakses:

Plaintext
http://localhost/kasir-tokoh-NIZI/
